These labs are designed and executed under resource-optimized and secure conditions:
* **Hypervisor:** Oracle VM VirtualBox.
* **Operating Systems:** Windows 10 Pro (Host), Debian 12 Minimal (VM nodes).
* **Network Security:** Isolated Host-Only virtual networks to ensure safe testing environments.
